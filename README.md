# Локальный мониторинг t72.ru

Укажите токен бота в `.env` (файл исключён из Git):

```dotenv
TELEGRAM_BOT_TOKEN=токен_бота
```

После этого запустите или перезапустите стек:

```bash
docker compose up -d --force-recreate alertmanager prometheus
```

Интерфейсы (доступны только локально):

- Prometheus: http://127.0.0.1:9090
- Alertmanager: http://127.0.0.1:9093
- Blackbox Exporter: http://127.0.0.1:9115

`https://t72.ru/` проверяется каждые 30 секунд. Алерт о недоступности срабатывает после 1 минуты ошибок; предупреждение об истечении TLS-сертификата — менее чем за 14 дней. Telegram получает firing и resolved уведомления в чат `-1005374082987`.

Проверяйте `probe_success` и `ALERTS` в Prometheus, а также состояние таргетов на `http://127.0.0.1:9090/targets`. Метрики хранятся в Docker volume `prometheus-data` 15 дней.

После изменения конфигурации примените её командой `docker compose up -d`.

Уведомления фактически отправятся после того, как вы зададите действующий токен в `.env`; токен не коммитьте.
